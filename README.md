# 🌿 Greenify — AI-Powered Plant Care & E-Commerce App

Greenify is an intelligent plant care and e-commerce mobile application developed as an academic project using Flutter. It combines AI-powered plant identification, plant disease detection, personalized care recommendations, and an online plant shopping experience into a single platform.

The application aims to help users understand plant health, identify potential diseases, receive personalized care guidance, and conveniently explore and purchase plants.

---

## 📱 About the Project

Greenify bridges the gap between plant care and technology by leveraging Artificial Intelligence, mobile application development, and cloud-based services.

Users can identify plant species, analyze plant health using images, receive customized care recommendations, and explore plants available for purchase. The application also provides features for nursery management, communication, and notifications.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android Emulator or a physical Android device
- Firebase project configuration

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/greenify.git
```

**2. Navigate to the project directory**

```bash
cd greenify
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Configure Firebase**

Connect the project to your Firebase project and add the required configuration files:

- `google-services.json` for Android
- `GoogleService-Info.plist` for iOS

Ensure Firebase services used by the application are properly configured.

**5. Run the application**

```bash
flutter run
```
